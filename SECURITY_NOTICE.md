# Security Notice

## Public repository warning

This source repository is intentionally public. Treat every committed file, issue, pull request, and workflow log as publicly visible. Never add passwords, access tokens, signing keys, private model/data files, personal information, or other secrets. A private-use app does not make a public repository private.

NOID AI is a personal assistant project for lawful use, learning, and authorized defensive security work.

## Allowed security scope

- Explain security concepts and secure coding practices.
- Help audit systems, applications, and websites when the user owns them or has explicit authorization.
- Support defensive analysis, vulnerability remediation, safe lab exercises, and responsible disclosure.

## Disallowed project behavior

- Unauthorized access, credential theft, malware deployment, persistence, destructive actions, or data exfiltration.
- Game cheating, stealth features, anti-cheat bypass, or evasion of detection.
- Bypassing Android security controls or another application's permission model.

## Sensitive actions

Actions that delete data, send messages, make purchases, change security settings, or disclose private information must require clear user confirmation. Maintain an auditable record of consequential actions.

## Reporting

Do not include real secrets, access tokens, private keys, or personal data in issues or logs. Report security problems privately to the repository owner.
